# "Continuous learning" means scheduled re-estimation with a human gate

The system measures everything and, on a schedule, proposes parameter updates with Walk-Forward evidence attached. A human approves or rejects each proposal. Prompts are versioned files changed only by a human. No component changes its own parameters, prompts, or code from recent performance. An agent that rewrites its strategy from last month's P&L is an overfitting machine with a fast feedback loop, and the cost of a bad autonomous change in a live account is unbounded.
